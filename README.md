Student Management System

Project Description

The Student Management System is a database project developed using MySQL and Python. It stores student details, including admission numbers, names, sections, subject marks, addresses, and contact information.

Features

* Store student details in a MySQL database.
* Add new student records.
* Search for student records using admission numbers.
* Modify existing student details.
* Delete student records when required.
* View student information and subject marks.

Database Structure

Database Name: student_db

Table Name: students

Fields

* admno – Student admission number (Primary Key)
* stuname – Student name
* section – Student’s section
* math – Mathematics marks (out of 20)
* physics – Physics marks (out of 20)
* chemistry – Chemistry marks (out of 20)
* computer – Computer Science marks (out of 20)
* English – English marks (out of 20)
* address – Student address
* contact – Student contact number

Technologies Used

* MySQL
* Python

Project Files

* student_database.sql – SQL script for creating the database and student table, and inserting sample records.
* main.py – Python application for managing student records (to be added).

How to Run

1. Install MySQL Server and MySQL Workbench.
2. Execute the SQL script in MySQL Workbench.
3. Install Python and the required MySQL connector.
4. Run the Python application to manage student records.

Note

The student records used during development are fictional sample data for demonstration purposes.
